Grocery pricing API

Connect a ReefAPI account to prepare automatic grocery price lookups for Price Chopper, Walmart, Hy-Vee, and ALDI. Live price fetching is not enabled yet; saving a key does not spend credits.

  1. Visit reefapi.com and sign up. ReefAPI currently advertises 1,000 free credits without a credit card.
  2. In the ReefAPI dashboard, find and copy your API key.
  3. Paste the key into the password box below and click Save API key.
  4. Look for the confirmation that your key was saved. It stays on this server and will not be displayed again.
  5. Once live pricing is implemented, we can test store availability by ZIP code and use credits only for requested lookups.

Keep your API key private. ReefAPI is a third-party provider; pricing and retailer coverage are subject to its service. You can remove your saved key below at any time.
